Acerca de FCA Tareas

FCA Tareas es un prototipo funcional de Front-End desarrollado como parte de la Unidad 3 de la asignatura Desarrollo de Aplicaciones Web, de la Licenciatura en Informática del SUAyED, Facultad de Contaduría y Administración, UNAM. Su propósito es demostrar la estructura y la interacción básica de una aplicación web para la gestión de tareas académicas, antes de implementar su lógica de negocio en el Back-End.

Reflexión sobre el desarrollo

¿Cómo cambia la experiencia del usuario cuando una página web puede responder a sus acciones (como pasar el mouse o hacer clic) en comparación con una página que solo muestra información estática?

Una página estática únicamente presenta información de forma pasiva: el usuario la lee, pero no recibe ninguna respuesta inmediata ante sus acciones, lo que puede hacer que la navegación se sienta rígida o poco intuitiva (por ejemplo, no sabría si un clic realmente fue registrado hasta que la página completa se recargue). En cambio, en este prototipo, elementos como el resaltado de las tarjetas del Dashboard al pasar el mouse, la validación inmediata del formulario de inicio de sesión, el filtrado en tiempo real del listado de tareas y el saludo dinámico según la hora del día le muestran al usuario, de forma instantánea, que la aplicación está "viva" y reacciona a lo que hace. Esto genera una sensación de control, inmediatez y confianza, ya que el usuario recibe retroalimentación constante sin tener que esperar a que el servidor procese y vuelva a enviar toda la página.

Reflexiona sobre la importancia de JavaScript en el desarrollo profesional, considerando su capacidad para realizar actualizaciones en tiempo real sin necesidad de recargar la página completa.

JavaScript es, hoy en día, prácticamente indispensable en el desarrollo web profesional porque permite manipular el DOM (Document Object Model) directamente desde el navegador, actualizando solo las partes de la página que realmente cambian —como el mensaje de validación de un formulario o las filas visibles de una tabla filtrada— en lugar de recargar el documento completo. Esta capacidad no solo mejora la velocidad percibida de la aplicación, sino que también reduce la carga en el servidor y en la red, ya que muchas interacciones (como la validación de este formulario de login) pueden resolverse del lado del cliente antes de siquiera comunicarse con el Back-End. En el desarrollo profesional, dominar JavaScript —y, más adelante, las peticiones asíncronas hacia una API, que se abordarán en unidades posteriores— es lo que distingue a una página informativa de una verdadera aplicación web interactiva.
